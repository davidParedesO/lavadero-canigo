# Lavadero Canigo

Vista previa de la web de Lavadero Canigo (lavadero de coches en Cartagena).

Página estática: `index.html` + `img/`. Las imágenes son ilustraciones de prueba y los precios son orientativos, pendientes de confirmar con el cliente.
Lleva `noindex` mientras es una vista previa; quitarlo al publicar en el dominio definitivo.

Sin cookies ni peticiones a terceros: las fuentes (Unbounded y Figtree, licencia OFL) se sirven desde `fonts/`, así que no hace falta banner de cookies. Si se añade Google Analytics o un mapa de Google incrustado, habrá que poner banner.
